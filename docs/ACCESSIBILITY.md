# アクセシビリティ

最終更新：2026-11-07

## 優先事項と目標

このリポジトリは、ほかの人が作ったウェブサイトの見た目や動きを、使う人の都合に合わせて直すためのユーザースクリプト集です。読みにくい色を変える、勝手に開いて邪魔になるメニューを隠す、コピーできない文字をコピーできるようにする、といった小さな変更ですが、どれも「サイトがそうなっているから仕方ない」と我慢していた困りごとを減らすためのものです。

たとえば、薄いグレーで書かれたリンクはロービジョンの人には見分けにくく、マウスを載せただけで開くメニューは、画面を拡大している人や手の震えがある人にとって、ほかの内容を覆い隠す障壁になります。こうしたスクリプトが、かえって別の人の使いにくさを生まないように気をつけています。

この文書が対象とするのは、次のとおりです。

- 各ユーザースクリプトが、対象サイトの見た目と操作に与える影響

対象サイトそのもののアクセシビリティや、Tampermonkey の画面は対象外です。

スクリプトが対象サイトに加える変更は、WCAG 2.2 のレベル AA を目標とし、これを上限ではなく下限と考えています。AAより厳しい独自の基準もあります（[貢献者への期待](#貢献者への期待)を参照）。第三者による試験は受けていないため、これは目標であり、適合を表明するものではありません。

## 各スクリプトがサイトに加える変更

### Notion - リンクとボタン枠の視認性改善

- リンク・メンション・目次・未入力のプロパティ・コメントの日付など、クリックできる薄いグレーの文字を、ライトテーマでは濃い青（`#00118F`）、ダークテーマでは明るい水色（`#99F2FF`）にします。Notion の標準の背景色に対するコントラスト比は、どちらも 12:1 以上です
- 半透明の極細の下線を、ブラウザ標準の太さと文字と同じ色の下線に戻します
- ボタンブロックの枠線を `#949494` にし、白い背景に対して 3:1 以上にします

### 宝くじ公式サイト・楽天ブックス - 下層メニュー非表示

- マウスを載せると開く下層メニューを、表示しないようにします。下層メニューにあったページには、最初から表示されているメニューからたどれるため、移動できなくなるページはありません

### TOKYOふたりSTORY - プロフィールと写真を新しいタブで開く

- プロフィールへのリンクと、プロフィール写真を、新しいタブで開くようにします
- クリック時のスクリプトで開いていたプロフィールや、リンクになっていなかった写真を、`href` を持つふつうのリンクにします。そのため、Tab キーで移動して Enter キーで開けるようになります

### TOKYOふたりSTORY - コピー・右クリック禁止を解除

- 文字の選択・コピー・右クリックを妨げる処理を解除します。選んだ文字を読み上げる機能や、翻訳・辞書などのツールに文字を渡しやすくなります

## 対応している環境

- ブラウザ：Google Chrome、Microsoft Edge（Tampermonkey を入れた状態）で動作を確認済み
- OS：Windows で動作を確認済み。macOS などほかの OS では、まだ試していません
- スクリーンリーダー：まだ試していません
- スクリプトそのものに操作する画面はありません。インストールや、有効・無効の切り替えは Tampermonkey の画面で行います。スクリプトを入れても、Tab キーでの移動や Enter キーでのリンクの操作など、ブラウザ標準のキーボード操作は妨げません（コピー・右クリック禁止を解除するスクリプトについては、[既知の制限](#既知の制限)を参照）

## 既知の制限

- **対象サイトが変更されると、スクリプトが効かなくなったり、意図しない見た目になったりすることがあります。** どのスクリプトも、対象サイトの HTML の構造やクラス名に合わせて作っているためです。
  - 回避策：Tampermonkey のダッシュボードで、そのスクリプトだけを無効にできます。修正版が出るまでは無効にしたうえで、GitHub Issues でお知らせください。
- **TOKYOふたりSTORY でコピー・右クリック禁止を解除すると、サイト独自のキー操作やマウス操作が効かなくなることがあります。** 禁止を解除するために、キーを押す・離す操作とマウスボタンを押す操作がサイト側の処理に届かないようにしているためです。Tab キーでの移動や文字の入力など、ブラウザ標準の操作はそのまま使えますが、サイトが独自に用意している操作（Esc キーでウィンドウを閉じる、など）は動かない場合があります。
  - 回避策：その操作が必要なときだけ、Tampermonkey でこのスクリプトを無効にしてください。
- **TOKYOふたりSTORY でプロフィールや写真を開くと、予告なく新しいタブが開きます。** スクリーンリーダーによっては、新しいタブに切り替わったことが伝わらない場合があります。元のページに戻るときは、ブラウザの「戻る」ではなく、タブを閉じてください。
- **TOKYOふたりSTORY で新しくリンクにした写真は、読み上げられるリンクの名前を、写真の代替テキストに頼っています。** サイト側で写真に代替テキストが付いていない場合は、リンク先が何か分からないことがあります。
- **Notion のスクリプトの色は、Notion の標準の背景色に合わせて選んでいます。** 背景色を付けたブロックやコールアウトの中では、コントラスト比が足りなくなる場合があります。また、ユーザースクリプトはブラウザでしか動かないため、Notion のデスクトップアプリやモバイルアプリには効きません。

## アクセシビリティの問題を報告する

問題は [GitHub Issues](https://github.com/securecat/tampermonkey-userscripts/issues) で報告してください。日本語でも英語でも構いません。

次のことを書いてもらえると助かりますが、どれも任意です。

- 何をしようとしていたか
- 使っていたスクリプトと、対象サイトのページのURL
- 何が起きたか、どうなると思っていたか
- OS、ブラウザのバージョン、Tampermonkey のバージョン、スクリプトのバージョン
- 使っている支援技術（スクリーンリーダーなど）

障害の有無や内容を書く必要はありません。スクリーンショットや録画も必須ではありません。

## 対応の流れ

このユーザースクリプト集は個人で開発しているため、返信や修正の期限はお約束できません。それでも、できるかぎり早く対応します。

- 報告を確認したら、Issue で返信します
- 回避策があれば、お知らせします
- 修正をリリースする前に、問題が解消したかどうかの確認をお願いすることがあります
- 修正したスクリプトは、`@version` の番号を上げます。変更の内容は、コミット履歴で確認できます

## 貢献者への期待

ここに挙げることは、人間の貢献者にもコーディングエージェントにも、同じように求めます。

ユーザースクリプトは、ほかの人が作ったサイトに後から手を加えるものです。元のサイトのアクセシビリティの問題をすべて解決することはできず、サイトのつくりや目的によっては、どうにもならないこともあります。それでも、スクリプトで対象サイトの見た目や動きを変えるときは、次のことを心がけてください。アクセシビリティの改善を主な目的とするスクリプトでは、特に大切にしてください。

- フォームにはネイティブの要素（`<input>`・`<select>`・`<textarea>`）を使う。`<div>` や `<span>` をボタンの代わりにしない。画面内の操作には `<button>`、ページの移動には `<a>` を使う
- `disabled` 属性を使わない
- フォーカスインジケーターを消さない（`outline: none` を使わない）
- リンクの下線を消さない
- テキストのコントラスト比は、本文で 7:1 以上、補足的なテキストで 4.5:1 以上にする。ライトテーマとダークテーマのそれぞれで満たす
- 境界線やアイコンなど、テキスト以外の要素も、隣り合う色に対して 3:1 以上にする
- コントラストが必要な要素に `opacity` を使わない
- 文字サイズは、日本語で 16px 以上、英語で 14px 以上にする
- `font-family` は `sans-serif` にする（`system-ui` は使わない）
- ステータスメッセージを自動で消さない
- 自動スクロールなど、ひとりでに動くものを作らない

変更したあとは、スクリプトを入れた状態の対象サイトを、キーボードだけで操作できること、スクリーンリーダーで内容が正しく読み上げられることを確認してください。

このリポジトリならではの注意として、次のことも心がけてください。

- 色を変えるときは、対象サイトにダークテーマがあれば、ライトテーマとダークテーマのそれぞれに値を用意し、サイトの標準の背景色に対するコントラスト比を確かめる
- 要素を `display: none` などで隠すときは、その中にあったリンクや情報に、別の経路でたどり着けることを確かめる
- キーボードのイベントを、必要な範囲を超えて止めたり横取りしたりしない
- 画像などをリンクにするときは、`href` を持つ `<a>` にし、リンクの名前が読み上げられることを確かめる
